# Bộ biểu VTVL phường Chợ Lớn

[Bấm để tải file ZIP chứa Excel](https://github.com/violantmt/ChoLon/raw/refs/heads/main/Bo_bieu_VTVL_Phuong_Cho_Lon_Du_thao_ra_soat.xlsx.zip)

Giải nén để lấy file `Bo_bieu_VTVL_Phuong_Cho_Lon_Du_thao_ra_soat.xlsx`.

Đây là bản dự thảo rà soát cho toàn khối Đảng ủy và MTTQ phường Chợ Lớn. Dữ liệu còn thiếu được để trống hoặc ghi chú; nội dung phân rã sơ bộ ngoài UBKT cần đơn vị xác nhận. Chưa kết luận số người cần bố trí hoặc dự báo biên chế.

Mở sheet `CL_GHI_CHU` và `CL_DOI_CHIEU_TG` trước khi sử dụng. Một số tổng giờ ở biên bản nguồn cần UBKT kiểm tra lại. Mở bằng Microsoft Excel và cho phép tính lại công thức.
